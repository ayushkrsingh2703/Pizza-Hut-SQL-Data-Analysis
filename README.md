# 🍕 Pizza Hut Sales Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analysing pizza sales data using
MySQL to identify important business insights and understand
sales performance.

The main objective is to explore customer ordering patterns,
popular pizza choices, revenue generation, and sales trends
through SQL queries.

## 🛠️ Tools Used
- MySQL
- MySQL Workbench
- GitHub

## 📊 Key Analysis Performed

1. Total number of orders placed.
2. Total revenue generated.
3. Highest-priced pizza.
4. Most frequently ordered pizza size.
5. Most ordered pizza type.
6. Total quantity of pizzas sold.
7. Total quantity sold by pizza category.
8. Distribution of orders by hour.
9. Category-wise sales distribution.

## 💡 SQL Concepts Used

- SELECT
- Aggregate Functions
- GROUP BY
- ORDER BY
- Joins
- Subqueries
- Date and Time Functions

## 🎯 Project Objective

To use SQL for analysing pizza sales data,
identifying customer preferences, understanding
sales trends, and generating meaningful business insights.

## 📚 Learning Outcomes

- Improved SQL query-writing skills.
- Hands-on experience with real-world datasets.
- Better understanding of sales data analysis.
- Ability to extract meaningful insights using SQL.
