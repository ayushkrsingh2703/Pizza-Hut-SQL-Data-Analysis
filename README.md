# 🍕 Pizza Hut Sales Data Analysis Using SQL

## 📌 Project Overview

This project explores pizza sales data using MySQL to understand order volume, revenue, customer ordering patterns, and product performance.

The goal is to turn raw sales data into useful business insights by writing SQL queries and analysing the results.

## 🎯 Project Objectives

- Measure the number of orders and the revenue generated.
- Identify popular pizza sizes and pizza types.
- Analyse the quantity of pizzas sold.
- Explore order patterns by hour and by day.
- Compare sales and quantity across pizza categories.
- Identify pizzas that perform well in terms of revenue.

## 🧰 Tools & Technologies

- **Database:** MySQL
- **SQL Environment:** MySQL Workbench
- **Version Control:** Git and GitHub
